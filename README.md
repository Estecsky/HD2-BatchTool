# HD2 Batch Tool
支持Blender 4.x-5.2 的《Helldivers 2》人物模型准备插件。当前职责为第三人称工作骨架、人物比例吸附、顶点组字典、权重整理和部位标记。

## 主要功能

- 导入第三人称潜兵工作骨架，并按人物自身比例完成骨骼吸附；
- 转回初态时同步烘焙网格、实际加权额外骨和物理依赖。
- 内置 `mmd通用`、`cats修复` 顶点组字典，也可新建、编辑和导入用户字典；
- 只重命名字典明确列出的权重组，并按潜兵式肩—肘—腕过渡整理手臂权重；
- “按物理链切分”独立于普通自动切割：按链根的实际骨骼祖先确定头、躯干、髋部、左右臂和左右腿归属，正权重及链组连接保证整链面不被拆开；躯干辅助骨对裙根的混合权重不改变链的归属。切后不要手调物理部位网格、拆分或跨部位移动。
- 自动人物缩放(可关闭)：关闭后吸附沿用作者当前尺寸/位置，头部偏移随之停用，不撤销之前的缩放。
- 可对用户已经拆好的网格手动指定语义部位；默认显示由唯一具名基础组提供，身体差分按具名组制作，同组每个部位最多一个差分，头盔差分单独命名；

## 自由搭配差分

“部位与差分指定”新增“差分逻辑”选单。默认“组差分”沿用原来的具名身体组和头盔单差分。
“自由搭配差分”让每个语义部位拥有一份独立列表：先选类型和部位，填写“差分部位名称”
（例如上衣、腿部、头饰），添加具体差分并在列表内直接重命名。选中活动差分项后才可标记网格；
每项一个网格，多块组成同一项时先合并网格。头盔 `Head` 同样支持这套自由差分。

部位选单另增加 `Torso_Armor`（胸甲），与 `Torso`（胸部/上躯干）分别标记。
自动切割仍产出原七部位；胸甲由作者准备并手动指定。

## 推荐流程

1. 导入人物模型，再点击“导入第三人称工作骨架”。
2. 同时选择人物来源骨架和潜兵工作骨架；插件按标记识别工作骨架。
3. CATS 修复后的模型选择“cats修复”字典；原始 PMX/MMD 可选择“mmd通用”。其他来源模型可新建空白字典或复制当前字典后逐条编辑。
4.  (可选操作)设置头部对齐偏移。插件按脚部权重网格识别可见接地面，并围绕脚底统一缩放人物骨架和绑定网格。
5. 依次执行“检查字典与骨架”“骨骼吸附”“顶点组重命名”。KEEP 模式把未映射的实际加权辅助骨保留到工作骨架；有物理项目时也会保留并转移所需骨。需要物理的模型不要选父链合并模式。
6. 点击“自动切割”。插件生成七个真实场景对象并清理空顶点组；特殊模型如需手切，由用户自行维护。

## 骨骼字典

插件同时枚举随包的 `presets/bone_name_list/*.py` 和 Blender 用户配置目录中的自建字典。方向固定为
`[来源名称, 潜兵目标名称]`：

```python
snap_bone_fixed_name_list = [
    ["来源骨盆", "hips"],
    ["来源左上臂", "l_shoulder"],
]

rename_vg_fixed_name_list = [
    ["来源骨盆权重", "hips"],
    ["来源左上臂权重", "l_shoulder"],
]
```

## 七部位与法向

自动切割先复制完整网格，再删除不属于目标槽位的面，最后把原面角法向写回自定义分裂法向。多源
网格合并后会再次验证，最大误差超过 `1e-3` 就中止。头部独立作为头盔替换部位；

# HD2 Batch Tool
支持Blender 4.x-5.2 的《Helldivers 2》人物模型准备插件。
当前职责为第三人称工作骨架、人物比例吸附、顶点组字典、权重整理和部位标记。

## 主要功能

- 导入第三人称潜兵工作骨架并可转为T-pose；
- 转回初态时同步烘焙网格、实际加权额外骨和物理依赖。
- 内置 `mmd通用`、`cats修复` 顶点组字典，也可新建、编辑和导入用户字典；
- 只重命名字典明确列出的权重组，并按潜兵式肩—肘—腕过渡整理手臂权重；
- “按物理链切分”独立于普通自动切割：按链根的实际骨骼祖先确定头、躯干、髋部、左右臂和左右腿归属，正权重及链组连接保证整链面不被拆开；切后不要手调物理部位网格、拆分或跨部位移动。
- 自动人物缩放(可关闭)：关闭后吸附沿用作者当前尺寸/位置，头部偏移随之停用，不撤销之前的缩放。
- 可对用户已经拆好的网格手动指定语义部位；默认显示由唯一具名基础组提供，身体差分按具名组制作，同组每个部位最多一个差分，头盔差分单独命名；
- 差分配置标记
  - 组差分：为多个差分部位分别标记，保存后可在reshade面板中实时切换
  - 自由搭配差分: 让每个语义部位拥有一份独立列表：先选类型和部位，填写“差分部位名称”
（例如上衣、腿部、头饰），添加具体差分并在列表内直接重命名。选中活动差分项后才可标记网格；每项一个网格，多块组成同一项时先合并网格。头盔 `Head` 同样支持这套自由差分。
- 骨骼字典：插件同时枚举随包的 `presets/bone_name_list/*.py` 和 Blender 用户配置目录中的自建字典。方向固定为
`[来源名称, 潜兵目标名称]`：

  ```python
  snap_bone_fixed_name_list = [
      ["来源骨盆", "hips"],
      ["来源左上臂", "l_shoulder"],
      ]
  
  rename_vg_fixed_name_list = [
      ["来源骨盆权重", "hips"],
      ["来源左上臂权重", "l_shoulder"],
      ]
- 七部位与法向: 自动切割先复制完整网格，再删除不属于目标槽位的面，最后把原面角法向写回自定义分裂法向。多源；网格合并后会再次验证。头部独立作为头盔替换部位；

## 推荐流程

1. 导入人物模型，再点击“导入第三人称工作骨架”并将工作骨架转为T-pose，对应发布骨架类型必须选择，选择女性会在游戏中启用双腿运动调整。
2. 调整人物模型并同样摆成T-pose并对齐工作骨架，腿部无需对齐。
3. CATS 修复后的模型选择“cats修复”字典；原始 PMX/MMD 可选择“mmd通用”。其他来源模型可新建空白字典或复制当前字典后逐条编辑。
4.  (可选操作)设置头部对齐偏移并打开人物统一缩放。插件按脚部权重网格识别可见接地面，并围绕脚底统一缩放人物骨架和绑定网格。
5. 同时选择人物来源骨架和潜兵工作骨架，骨骼吸附与重命名+重绑按钮将激活。依次执行“检查字典与骨架”“骨骼吸附”“顶点组重命名”。有物理项目时也会保留并转移所需骨。需要物理的模型不要选父链合并模式。自行选择未映射权重的处理方式：
   - 保留：未映射的实际加权辅助骨保留到工作骨架；
   - 合并：直接合并到父级骨。
6. 完成骨骼吸附与重命名+重绑后，必须点击转回初态+原始骨轴
7. 然后使用计算并调整持握骨得到相对较优位置，或自行手动调整位置，也可手动调整其他骨位置
8. 部位切分，选择自动切割或手动切分
9. （重要）为切分的部位指定对应部位标记，只有带标记的模型才能在之后使用SDK保存
